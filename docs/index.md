# ProjectFusion Warpzones Documentation

Welcome to the documentation for ProjectFusion Warpzones.

This plugin lets you define 3D regions as "warp zones" that players can use like elevators: jump to go up, sneak to go down. Zones can be stacked within a world or even span multiple worlds.
